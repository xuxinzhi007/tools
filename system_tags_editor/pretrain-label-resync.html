任务标签重刷对齐

一次只生成一条规则。查询从 tb_collection 关联 tb_device、tb_job。 卡片上的条件就是当前规则，改完再点这一条的查询或刷入。后三列是要写入的目标。

规则

留空的条件不写进 SQL。排在前面的规则优先，后面的查询会排除已经命中的更早规则。场景走 tb_job_tag.relation_type = SCENE。

无本体设备

勾选的型号算无本体，未勾选的算有本体。设备条件写在 tb_device.device_model 上，topic 写在 tb_collection.topic 上。

生成的 SQL

先点某一条规则的「查询」。确认行数和创建人之后，再生成这一条的「刷入」。
